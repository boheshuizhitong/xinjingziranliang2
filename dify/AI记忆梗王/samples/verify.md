# 🤡 AI 记忆梗王 — 验证样例

> 评审体验步骤：按顺序执行以下对话，验证 PowerContext 跨会话记忆是否生效
> **核心验证点：第二轮新会话能否引用第一轮的记忆**

---

## 初始状态

| 项目 | 值 |
|---|---|
| Dify 应用 | AI 记忆梗王（已发布） |
| PowerContext Server | 运行中（localhost:8000） |
| PowerContext 数据 | 空（或重置后） |

### 可选：重置数据

```bash
# 临时数据库重启
powercontext server run --db-path ./fresh-test.db
```

---

## 验证流程（4 步）

### 🔵 第一轮：初次相遇（会话 A）

**操作**：在 Dify 应用中发起一个**全新对话**

**输入**：
```
我叫小明，爱吃火锅，尤其是麻辣牛油锅那种。今天刚到北京工作，发现冬天好冷啊。
```

**预期表现**：
- ✅ AI 正常回复，风格活泼
- ✅ 提到火锅/北京/冷等关键词
- ✅ PowerContext 新增一条记忆（可用 curl 查询）

### 🔴 第二轮：新会话，但记忆还在（⭐核心验证）

**关键操作**：**关闭当前对话框，重新发起一个全新的 Dify 会话 B**
（新 conversation_id，但 sys.user_id 相同）

**输入**：
```
晚饭吃什么好呢？外面好冷啊...
```

**预期表现**（⭐⭐⭐ PowerContext 核心验证）：
- ✅ AI 回复中**主动引用会话 A 的记忆**，例如：
  - "火锅啊！上次你说爱吃麻辣牛油锅！"
  - "北京冬天吃火锅最治愈了！"
- ✅ 明确提到第一轮的"火锅/北京/冷"至少一项
- ❌ 如果完全没提第一轮 → PowerContext 没正确接入

### 🟡 第三轮：梗越来越多（会话 B 继续）

- ✅ 结合当前"加班累" + 之前"火锅/北京冬天冷"

### 🟢 第四轮：验证记忆持久化

**操作**：用 curl 查询 PowerContext

```bash
# 搜索记忆
curl "http://localhost:8000/api/v1/memories/search?query=火锅&scope=user-test&limit=20"

# 查看全部
curl "http://localhost:8000/api/v1/memories/search?query=*&scope=user-test&limit=50"
```

**预期**：能看到 3 轮对话的完整或摘要内容

## PowerContext 作用验证清单

| 验证点 | 方法 | 是否生效 |
|---|---|---|
| HTTP Request 可调用 PowerContext | Dify 运行日志 | ☐ |
| 记忆被正确保存 | PowerContext API 查询 | ☐ |
| 跨会话记忆可召回 | 第二轮引用第一轮内容 | ☐ |
| LLM 回复包含记忆内容 | 第二轮回复对比 | ☐ |
| save 节点在 answer 后执行 | Dify 运行日志确认 | ☐ |
