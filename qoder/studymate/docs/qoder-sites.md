# Qoder Sites 发布指南（docs/qoder-sites.md）

> 本赛道要求：项目网站必须通过 **Qoder Sites** 发布，且可见范围设置为
> 「任何人都可访问」（企业版账号无法设置公开访问，请使用个人账号）。

## 1. 网站内容建议（评审入口）

在 Qoder Sites 上创建项目网站，建议包含以下板块（可直接引用本仓库内容）：

| 板块 | 内容 |
| --- | --- |
| 项目简介 | 一句话：学伴 StudyMate —— 越用越懂你的学习记忆助手（seekdb 知识检索 × PowerContext 跨会话记忆） |
| 解决的问题 | 复习找不到笔记 / 学了就忘不知薄弱点 / 进度每次重讲 |
| 核心功能 | 知识库混合检索、记忆教练、今日复习计划（配截图） |
| 演示 | 运行 `samples/verify.py --reset` 的 17/17 通过截图，或操作录屏 |
| 代码仓库 | 本仓库链接（含 `qoder/studymate/` 目录） |
| 体验入口 | 引导评审按 `run.md` 启动本地体验（本地服务无法公网托管） |
| 使用效果（可选） | 站点"访问统计"截图；真实用户反馈（隐去个人信息） |

## 2. 发布步骤（Qoder 内操作）

1. 打开 Qoder，进入 **Sites**（站点）模块；
2. 新建站点，选择模板/空白页，编辑上述内容；
3. 站点设置中确认可见范围 = **任何人都可访问**；
4. 点击 **发布**，获得形如 `https://xxx.qoderspace.com` 的公开链接；
5. **发布后修改内容需再次点击「发布」才会更新线上版本**；
6. 用浏览器**无痕窗口**打开站点链接，确认未登录可访问。

## 3. 提交核对清单

- [ ] 站点链接可在无痕窗口打开（未登录）
- [ ] 站点包含：项目简介、解决的问题、核心功能、演示截图、代码仓库链接
- [ ] Qoder 账号 UID 已填入 `docs/qoder-dev-log.md` 并在平台提交
- [ ] 评审结束前不暂停/删除站点
- [ ] 若展示访问统计/用户反馈，已隐去个人信息
